# Certamen Literario – Rúbricas de evaluación

Sitio para evaluar obras de **Cuento**, **Poesía** y **Microrrelato** con las rúbricas oficiales.

- Página: https://vilchezmarencoivan-netizen.github.io/certamen-literario/
- Las evaluaciones se guardan en una hoja de cálculo de Google mediante Google Apps Script.
- Usuarios: Ashly Rodríguez y Kathya Ugalde (profesoras) y Administrador.

| Archivo | Uso |
|---|---|
| `index.html` | La página web |
| `config.js` | URL del servidor (Apps Script) |

Las contraseñas no están en este repositorio: se administran en el proyecto de Apps Script.
